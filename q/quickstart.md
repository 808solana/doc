## Key takeaways

- The base URL is `https://api.luv13.ai/v1`.
- You need an API key starting with `sk-luv13-` from the dashboard.
- luv13's own examples use the model `luv13/glm-5.3-flash`.

The full Quickstart is at [Quickstart](/docs/quickstart).

- [Authentication](/docs/a/auth)
- [Pricing](/docs/p/pricing)
- [GLM-5.3 Flash](/docs/m/glm-5-3-flash)

To check the API is reachable:

```bash
curl https://api.luv13.ai/v1/models
```
